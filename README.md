# 🛡️ 反诈知识学习与测试

一个先看反诈宣传视频后答题的互动式教育网页，旨在提高用户防范电信诈骗的意识。

## 🌐 在线访问

**[https://yu2163328927-eng.github.io/anti-fraud-quiz/](https://yu2163328927-eng.github.io/anti-fraud-quiz/)**

## ✨ 功能

- 🎬 **先看后答**：必须观看两个反诈宣传视频后才能进入答题
- 📝 **8 道题目**：4 道单选 + 4 道多选，满分 100 分
- 📋 **详细解析**：每道题都有答案和详细解析
- 🏆 **合格判定**：60 分合格，合格有庆祝特效
- 🔄 **重复答题**：可多次答题，每次都有记录
- 📊 **历史记录**：按姓名追踪每次答题分数（第1次、第2次...）
- 📈 **数据统计**：管理员面板查看总览、用户列表、题目分析
- 💾 **数据导出**：支持导出 CSV（Excel 可打开）和 JSON
- 🔐 **密码保护**：管理员入口需密码验证
